`cudarc-fathomdb =0.21.0` and `candle-kernels-fathomdb =0.13.0`.
Source and qualification records live in
[coreyt/candle-fathomdb](https://github.com/coreyt/candle-fathomdb); package
VCS metadata, when present, identifies the exact source revision.
Qualification and registry publication are separate.
